### 第 2 部分：方案概览（Slide 5–8）

**Slide 5 — 一句话定位**

> **智服通 AgentOps**：嵌入企业既有系统的智能客服 Agent **运营中台** — 可演示、可度量、可回归。

**Slide 6 — 架构总览（一图）**

```
用户 → 对话 UI → Runtime Harness → Skill 编排 → 工单/CRM/知识库
                      ↓                    ↓
                 Guardrail            四层 Memory
                      ↓                    ↓
                 Trace 可视化      Eval Harness (120 条 CI)
```

- 强调：**不替换**贵司 5 年自研工单系统，API 嵌入

**Slide 7 — 四大差异化（对标「单 Prompt Demo」）**

| 能力 | 客户价值 |
|------|----------|
| **Skill 编排** | 意图/建单/检索边界清晰，Fallback 可控 |
| **Runtime Harness** | Guardrail + 步数限制，2B 确定性 |
| **四层 Memory** | 老用户不用重复描述（32%→≤10%） |
| **Eval 双 Harness** | Prompt 变更自动回归，敢迭代 |

**Slide 8 — 用户旅程（3 个典型场景）**

1. **知识咨询**：「企业版和专业版区别？」→ RAG + 来源引用  
2. **报修建单**：「服务器宕机」→ 自动建单 + 返回工单号  
3. **跨会话续办**：新会话问进度 → Episodic Memory Recall

- 配 UI Wireframe 缩略图（来自 20-ui-wireframes）
