## 议程（30 分钟）

| 时间 | 环节 | 动作 |
|------|------|------|
| 0–5 min | 开场 | 回顾痛点 P1–P5，展示今日 Demo 范围 |
| 5–15 min | **Live Demo** | ① 知识咨询+引用 ② 建单 ③ 查进度 Skill 边界 ④ 跨会话 Memory |
| 15–22 min | 现场迭代 | 客户点 2 个 Bad Case，现场改 Prompt/Skill |
| 22–28 min | Trade-off | 「全 LLM vs 混合 vs 全规则」投票 |
| 28–30 min | 下一步 | 确认 M2/M3 验收指标 |

## Demo 脚本（主持人）

1. **输入**：「企业版套餐包含哪些功能？」→ 展示 RAG 引用来源
2. **输入**：「我要报修，服务器宕机」→ 展示 ticket-create + 工单号
3. **输入**：「查一下刚才工单的进度」→ 强调只 invoke ticket-query
4. **新 Session**：「我的工单进度怎么样了？」→ 展示 Episodic Memory
