## 1. 信息架构

```
智服通 AgentOps
├── 对话（/chat）          ← 终端客户 / 坐席
├── 运营后台（/ops）       ← 主管 / 运营
│   ├── Skill 健康度
│   ├── Trace 查询
│   └── Bad Case
└── 评测报告（/eval）      ← 测试 / IT
```

## 2. 对话页 `/chat`

### 2.1 布局

```
┌────────────────────────────────────────────────────────────┐
│ 智服通 AgentOps    [对话] [运营后台] [评测报告]              │
├────────────────────────────────────────────────────────────┤
│ 智能客服对话                    Session: sess_xxx          │
├────────────────────────────────────────────────────────────┤
│ ┌────────────────────────────────────────────────────────┐ │
│ │ 你：企业版和专业版有什么区别？                            │ │
│ │ Agent：企业版包含… [1]                                   │ │
│ │   📎 来源：FAQ-012 企业版套餐说明                         │ │
│ │   trace: tr_abc123                                       │ │
│ │                                                          │ │
│ │ 你：帮我查 T-001 进度                                     │ │
│ │ Agent：工单 T-001 当前「处理中」…                         │ │
│ └────────────────────────────────────────────────────────┘ │
├────────────────────────────────────────────────────────────┤
│ [ 请输入问题…                          ] [ 发送 ]          │
└────────────────────────────────────────────────────────────┘
```

### 2.2 交互规则

| 元素 | 行为 |
|------|------|
| 消息气泡 | 用户右对齐 / Agent 左对齐 |
| 来源引用 | RAG 回答下方展示 `[1]` 可点击跳转 KB |
| trace_id | 小字灰色，供运营复制排查 |
| 发送 | Enter 发送；发送中按钮 disabled |
| 错误 | 红色提示「连接失败，请确认网络」 |
| Guardrail | Agent 回复黄色背景提示框 |

### 2.3 状态

| 状态 | UI |
|------|-----|
| 空闲 | 输入框可用 |
| 发送中 | 按钮「…」；禁止重复发送 |
| 被拦截 | blocked 消息 + 无 trace 链路 |

## 3. 运营后台 `/ops`

```
┌────────────────────────────────────────────────────────────┐
│ 运营后台                                                    │
├────────────────────────────────────────────────────────────┤
│ Skill 健康度                                                │
│ ┌─────────────┐ ┌─────────────┐ ┌─────────────┐           │
│ │intent-class │ │ticket-create│ │know-retrieve│           │
│ │ 成功率 92%  │ │ 成功率 88%  │ │ 成功率 85%  │           │
│ │ v1.0.0      │ │ v1.0.0      │ │ v1.0.0      │           │
│ └─────────────┘ └─────────────┘ └─────────────┘           │
├────────────────────────────────────────────────────────────┤
│ Trace 查询  [ trace_id: tr_abc123        ] [ 查询 ]         │
│ Guardrail → Memory → Skill → Tool → Guardrail              │
├────────────────────────────────────────────────────────────┤
│ Bad Case  归因: [Skill ▼]  [ 标记已修复 ]                   │
└────────────────────────────────────────────────────────────┘
```

| 功能 | 验收 |
|------|------|
| Skill 卡片 | 展示成功率、版本、Fallback 率 |
| Trace | 输入 trace_id 展示步骤时间线 |
| Bad Case | 七层归因下拉 + 备注 |

## 5. 嵌入客户系统（集成模式）

### 5.1 iframe 嵌入

```html
<iframe
  src="https://agentops.customer.com/chat?user_id={uid}&token={jwt}"
  width="400" height="600"
  sandbox="allow-scripts allow-same-origin allow-forms"
/>
```

### 5.2 API-only 集成

客户自研 UI，仅调用 `POST /api/v1/chat`，见 [15-api-specification.md](./15-api-specification.md)。
